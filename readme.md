# About Me - Django Project

This is a simple Django-based personal portfolio and blog site featuring an "About Me" page and a blog listing page. The project uses Django as the backend and Bulma for styling.

## Features
- "About Me" page with links to social profiles.
- Blog page listing posts from the database (latest first).
- Styled using Bulma CSS framework.
- Static assets served properly.

## Technologies Used
- **Python** (Django Framework)
- **Bulma** (CSS Framework)
- **HTML5 & CSS3**
- **SQLite3** (Default Django database)
